# 核心保持与复现范围

## 原样保留

`src/models.py`、`objectives.py`、`metrics.py`、`optimization_losses.py`、`sampler_objective.py`与实验源码逐字一致。没有改变网络参数、条件融合、目标变换、余弦扩散v预测、直线流路径、16步采样、损失系数及反传后缀。

`reference/`保留原始训练、第一阶段微调和实际采样微调调度源码；这些文件依赖历史项目布局，仅用于审查，不是新的运行入口。请通过根目录run.py操作。

## 可移植入口

`dataset.py/runtime.py/cli.py/common.py`是新整理的适配层，提供可配置数据路径、只读分批数据、单个训练运行、原始权重兼容、恢复、评价和绘图。不会在导入时或执行帮助命令时自动启动训练。

默认native阶段：96轮预算、至少48轮、每4轮固定screen评分，16轮无0.001实质CSI改善提前停；筛选前三候选加最终轮，再以完整验证复选。微调阶段：16轮、前两screen候选加原权重epoch0，完整验证复选。CSI差0.003内按POD/FAR/FSS次级排序；微调候选还检查汇总POD/FAR/RMSE保护条件。

这是**单运行**入口，不自动执行24项损失筛选、三训练种子的方案确认、多个训练种子的联合选模或72小时块bootstrap。原研究还经过完整三种子/四成员联合验证、预先锁定48项历史复核、独立数值和人工图像审计；只运行一次命令不等于重做这些步骤。

可移植入口的全验证保护条件按单次运行执行，而历史最终保留方案由多种子/多成员统一比较确定；不能宣称适配入口保证选到完全同一轮。CPU用FP32，CUDA默认BF16，也可能存在设备/版本数值差异。本次只做CPU合成检查及原权重兼容检查，没有重跑完整GPU训练来宣称逐位复现历史数值。

## 原始权重

加载器接受原selected.pt的`model`字典，也接受整理入口保存的同格式。生成目标的均值/标准差buffer保持不变；微调前核对与当前训练缓存一致。残差扩散必须配对原冻结底座，不能仅凭相同网络结构替换。

`provenance/historical_checkpoints.json`记录两方向三种子原/优化权重及底座哈希，不包含实际权重。代码包之外的本机权重索引给出当前服务器路径，便于作者私下定位。没有复制数据、权重、日志、第三方安装目录或认证设置。

## 输出口径

逐提前量累计混淆计数后计算CSI/POD/FAR；FSS累计邻域比例平方误差后计算；边缘邻域按真实格点数归一化。空分母记缺失，不记满分。预测先量化到FP16 dBZ再评分，与原导出产品口径一致。

多成员个人技巧均值与集合平均图技巧不同；曲线统计并非概率校准结果。测试评价入口先写固定权重/数据索引记录且不选权重，历史时段曾被查看这一事实不因重跑而改变。
